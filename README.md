# Hush

Hush — минималистичный приватный веб-сервис голосовых звонков между двумя людьми.

## Первый рабочий этап

- комнаты без регистрации;
- 6-символьные коды приглашения;
- максимум два участника;
- ссылки-приглашения;
- Socket.IO signaling;
- WebRTC peer-to-peer аудио;
- включение/выключение собственного микрофона;
- локальное заглушение собеседника;
- шумоподавление, echo cancellation и auto gain control;
- выбор микрофона;
- выбор динамика через `setSinkId`, если браузер поддерживает API;
- обработка отключения участника;
- `/health`;
- комнаты хранятся только в памяти процесса.

## Запуск Windows

Требуется Node.js 18+.

```powershell
npm install
npm start
```

Откройте `http://localhost:3000`.

Для теста двух участников удобно открыть Hush в двух разных окнах/профилях браузера. Разрешите микрофон в обоих окнах.

## Важно про WebRTC и приватность

WebRTC шифрует медиатрафик на транспортном уровне, но этот проект пока не является полностью независимым от инфраструктуры Hush и не содержит E2EE-механизма на уровне приложения. Сигналинг проходит через Socket.IO-сервер.

Сейчас используются публичные STUN-серверы. Для стабильной работы пользователей за сложными NAT/firewall понадобится TURN-сервер на следующем этапе.

Шумоподавление использует стандартные браузерные ограничения `noiseSuppression`, `echoCancellation` и `autoGainControl`. Поддержка конкретных возможностей зависит от браузера и устройства.

Выбор динамика использует `HTMLMediaElement.setSinkId()`. В браузерах без поддержки этого API поле выбора отключается.
