Wave — экспериментальный проект на PeerJS и WebRTC. Для работы микрофона нужен HTTPS и разрешение браузера.
Голос передаётся между участниками напрямую, когда соединение это позволяет. Для некоторых сетей может потребоваться TURN-сервер.

Выбор отдельного устройства вывода поддерживается не во всех браузерах. Если список недоступен, Wave будет использовать системное устройство по умолчанию.
